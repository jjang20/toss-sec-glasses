# PRD 결정 로그 (grilling)

이 문서는 grilling 세션에서 확정된 결정만 기록합니다. PRD 본문(`PRD.md`)은 이 로그를 근거로 작성합니다.
각 항목: 결정 · 이유 · 대안 · 트레이드오프 · 파생 영향.

---

## D1. 주 사용 상황 — 근무 중 "눈치 안 보는" 토스 사용

- **결정:** 근무 시간에 휴대폰을 꺼내 주식장을 확인하거나 거래하기 어려운 상황에서, 주변 사람에게 티 나지 않게 토스증권을 쓰는 것이 주 사용 상황이다.
- **이유:** 사용자가 직접 정의한 핵심 가치. 안경 화면은 착용자에게만 보이고, Neural Band 제스처는 손목 아래에서 작게 일어나 외부에서 거의 보이지 않는다 — 휴대폰 대비 이 기기만의 존재 이유.
- **대안:** (a) 이동 중 glance 중심 — 범용적이지만 "사회적 은밀함"이라는 차별점이 흐려짐. (b) 앉아서 집중 분석 — 휴대폰/PC가 더 낫다.
- **트레이드오프:** 사무실 맥락에 최적화하면 소리 내는 입력, 큰 손동작, 오래 응시하는 화면이 모두 불리해진다.
- **파생 영향 (후속 질문에서 확정 필요):**
  - 입력: 음성 명령은 사무실에서 "눈치"를 유발 → 입력 우선순위 재검토 (Q2)
  - 시선: 대화·업무 중 화면을 오래 보면 시선이 비어 보임 → 한 번 보기 시간 상한 필요
  - 거래 포함 확인됨 ("주식 거래") → 주문 플로우는 범위 안

---

## D2. 입력 우선순위 — Neural Band 단독 완결, 음성은 선택

- **결정:** 모든 기능(시세 확인, 이동, 주문 완료까지)은 Neural Band 제스처만으로 끝까지 수행 가능해야 한다. 텍스트 입력은 Neural Band 손글씨가 기본. 음성은 혼자 있을 때 쓰는 선택적 지름길이며, 음성이 없어도 불편하지 않아야 한다.
- **이유:** D1의 핵심 가치 "티 나지 않음"을 음성이 정면으로 깬다. 단일 입력으로 완결되면 설계 규칙도 단순해진다.
- **대안:** 음성 주 입력(사무실에서 사용 불가), 음성·제스처 동등(기능마다 기본 입력 결정 필요 → 복잡).
- **트레이드오프:** 종목명 입력이 느려진다(손글씨 < 음성).
- **파생 영향:** "종목을 고를 일 자체를 줄이는" 설계 필요 — 보유/관심 종목 중심의 즉시 접근. 제스처 어휘(gesture vocabulary)와 손글씨 입력의 실기기 리서치 필요.
